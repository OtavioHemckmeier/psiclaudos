# Fase 0 — Instrumento inicial

O projeto ainda não possui um instrumento clínico autorizado configurado. A fundação usa apenas um contrato genérico e um motor de regras com testes sintéticos.

## Checklist de liberação

- [ ] Confirmar se o primeiro instrumento será o ASRS-18.
- [ ] Obter autorização para reprodução e uso digital.
- [ ] Confirmar a modalidade de aplicação permitida.
- [ ] Receber a versão oficial, regras e tabelas normativas.
- [ ] Definir os campos que o psicólogo preencherá.
- [ ] Receber casos de entrada e saída para validação.
- [ ] Revisar a configuração com profissional habilitado.
- [ ] Registrar fonte, licença, versão e data de aprovação.
- [ ] Publicar a primeira versão somente depois dessas confirmações.

Até a conclusão, nenhum texto, ponto de corte ou regra clínica do instrumento real deve ser inserido no repositório.
